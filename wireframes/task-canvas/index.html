Wireframe

Infinite topic canvas

Each rectangle is a topic. Tasks live inside it. The canvas is unbounded, so topics can sit near related work, like stars in a constellation. The topics shown are sample placeholders.

Try it

  • Drag a topic by its header to move it
  • Drag empty space to pan; scroll or pinch to zoom
  • Double-click empty space to drop a new topic there
  • Double-click a topic name to rename it
  • Type in "Add task" and press Enter
  • Select a topic and press Delete to remove it
  • Click the minimap to jump around
