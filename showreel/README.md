# Claude — Motion Reel ’26

A 15-second, 1920×1080, 60 fps showreel. Every frame and every sound is generated by code: no keyframes, no assets beyond four open-source fonts (Inter, Instrument Serif, JetBrains Mono; OFL).

![poster](poster.jpg)

**Watch:** [`showreel.mp4`](showreel.mp4)

| # | Scene | What's happening |
|---|-------|------------------|
| 01 | Genesis | A dot pulses on the beat, squashes in anticipation, and smears into a line that splits into five color bars |
| 02 | Type | "MOTION" slot-rolls into "DESIGN". The period of "is my obsession." becomes an iris wipe |
| 03 | Form | A 256-vertex polar morph (circle → square → triangle → star) with echo trails and a ripple dot grid |
| 04 | Particles | 5,200 particles burst, spring into "CLAUDE", get scanned, then collapse into a vortex |
| 05 | Dimension | A Fibonacci sphere morphs into a (2,3) torus knot, then a warp-speed fly-through |
| 06 | Systems | A split-screen grid build (optics, rhythm, physics, flow) zooms out to 16 panels, then the panels flip away |
| 07 | Data | Counters, a bar chart, a line chart, and a progress ring on consecutive beats, then a lime wipe |
| 08 | Signature | An elastic name drop and a blur-in subtitle. The opening dot bounces back in as the full stop |

Everything is cut to a 128 BPM grid (one scene = one bar, so 8 bars = 15.0 s). The post chain adds camera shake, chromatic aberration on impacts, bloom, vignette and film grain, plus 4-sub-frame motion blur with a 180° shutter.

## Files
- `reel.js`: the animation. `render(t)` is a pure function of time.
- `index.html`: open it in a browser for a live real-time preview. Add `?t=7.5` to freeze on a single frame.
- `audio.py`: the soundtrack, synthesized with numpy (kick, clap, hats, bass, pad, arps, risers, and hits synced to the picture).
- `render.js`: renders the frames in parallel with headless Chromium (Playwright) and encodes them with ffmpeg.

## Rebuild
```sh
python3 audio.py audio.wav
node render.js video showreel.mp4 audio.wav   # needs playwright + ffmpeg (set FFMPEG=/path if not on PATH)
```
